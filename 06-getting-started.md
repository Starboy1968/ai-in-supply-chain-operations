# Getting started: a free or low-cost 30/60/90-day path

For a manager who wants to start with what they already have: **spreadsheets plus a general AI assistant** your company has approved. No new software in the first 60 days.

## Days 1-30: Ground rules and clean data

- **Check the rules.** Find out which AI tools are approved and what data may go into them. If none are approved, start with anonymized data only and talk to IT or security.
- **Pick one use case** that hurts and has data: freight invoice checks and slow-moving inventory are usually easier starts than forecasting.
- **Write down how it works today** (who does what, how long it takes, what goes wrong) so you can compare later. Describe it in words; numbers only from your own records.
- **Clean the data for that one area:** item codes, missing records, unusual periods marked.
- **Learn the basics** with the [how-to guide](02-use-cases/). Try the sample prompts on anonymized data.

## Days 31-60: Pilot side by side

- Run the AI-assisted method **alongside** the current one. Don't switch over yet.
- Name a reviewer for every output. Nothing goes to a supplier, customer or payment without a person checking it.
- Keep a simple log: what the AI suggested, what the person decided, and why.
- Hold a short weekly review: where did AI help, where was it wrong, what rule was missing?

## Days 61-90: Decide and expand carefully

- Compare before and after using your own records: time spent, problems caught, errors, the relevant KPIs from the use-case file.
- Decide: keep, adjust, or stop. Stopping is a valid result.
- If keeping: write a one-page procedure (who reviews, when to override, how to escalate), and pick the next use case.
- Only now consider paid tools, using the questions in the companion [vendor due diligence questionnaire](https://github.com/Starboy1968/ai-supply-chain-risk-assessment/blob/main/04-recommendations/vendor-due-diligence-questionnaire.md).

## Rules that stay in place from day one

1. Approved tools only; no confidential data in public chatbots.
2. A named person reviews and owns every decision.
3. Every override or rejection gets a one-line reason.
4. Bank-detail changes are always confirmed by calling a number already on file.
5. The manual way of working stays practiced, so you can fall back to it.
